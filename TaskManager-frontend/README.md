# Task Manager Frontend

React 19 + Vite frontend for the AWDF Practical 6 Task Manager.

## Requirements
- Node.js and npm

## Run locally
```bash
npm install
npm run dev
```

## Build and lint
```bash
npm run build
npm run lint
```

The UI expects an API at `http://localhost:5000/tasks`. The backend source was not present in the supplied archive; run your API separately.
